Privacy Policy — claude-personal

Last updated: November 2, 2026

claude-personal is a single-user application used only by its owner to access the owner's own Google account.

Data accessed

With the owner's consent via Google OAuth, the app can read and modify the owner's Gmail, Google Drive, Docs, Sheets, Slides, Calendar, Forms, Tasks and Apps Script data.

How data is used

Data is used only to perform actions the owner requests through their local AI assistant. It is not sold, shared with third parties for advertising, or used to train models by this app.

Storage

OAuth tokens are stored locally on the owner's machine. No data is stored on any server operated by this app.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
